# До России

Интерактивная презентация: «Первобытные люди и их стоянки на территории современной России». Семь сцен на React 19, TypeScript, Vite и GSAP. Все изображения и шрифты локальные; после загрузки показ не зависит от внешних сервисов.

## Запуск

```sh
npm ci
npm run dev -- --port 4173
```

Открыть http://localhost:4173. Для доски в той же сети: адрес Network из терминала Vite.

## Управление

- `←`, `→`, `Пробел` — переход между сценами.
- `R` — повторить вход текущей сцены.
- `F` — переключить полный экран; `Esc` — выйти или закрыть открытое изображение/источники.
- Горизонтальный свайп более 80 px — перейти; вертикальный свайп и колесо сцены не переключают.
- Кнопка слева вверху — содержание, источники, полный экран, упрощённые переходы.
- Нажатие на музейный материал — увеличить его без обрезки изображения.
- `/#1` … `/#7` — прямой вход; перезагрузка сохраняет сцену.
- После финальной сцены стрелка вправо гасит экран; «С начала» возвращает к первой сцене.

Базовая сцена 1920×1080 пропорционально вписывается в окно. Навигация находится отдельно от масштабируемой сцены: 88×88 px на desktop, 112×112 на 4K, 56×56 на узком экране.

## Проверка

```sh
npm run build
npm test
```

Тесты используют установленный Google Chrome и сервер на порту 4173. Проверяют все сцены, загрузку изображений, защиту от повторных нажатий, возврат в HOLD, replay, меню, источники, прямые URL, reduced motion, финальный black state, restart, отсутствие прокрутки, клавиатуру после клика, увеличение изображений, свайпы и отказ загрузки.

Режиссура перехода: содержимое исчезает → круговая маска закрывает неподвижный фон → камера отдаляется к общей карте → приближается к точке следующего/предыдущего места → круг плавно раскрывает неподвижное полноэкранное фото → содержимое появляется по одному блоку. Фоны занимают весь экран, расположение карточек сохранено. Один GSAP timeline управляет всей цепочкой; повторных анимаций одного блока нет.

`tests/motion.spec.ts` проверяет оба направления, соответствие фотографий стоянкам, единственный запуск каждого блока, последовательное появление, полноэкранные фоны и геометрию камеры/маски: во время раскрытия фото сохраняет размер и положение экрана. Производительность: `node scripts/profile-motion.mjs 1` (обычный CPU) или `4` (замедление CPU в 4 раза). Отчёт: `qa/motion-profile-N.json`.

Для движения камеры используется растровый снимок карты: он исключает перерисовку SVG при увеличении. После изменения карты обновить его при запущенном dev-сервере: `node scripts/build-map-snapshot.mjs`.

## Данные и материалы

- `src/data/sources.ts` — авторы, первоисточники и лицензии.
- `src/data/locations.ts` — координаты четырёх памятников.
- `src/data/russia.json` — Natural Earth, public domain.
- `src/animation/controller.ts` — входы и пространственные переходы.
- `public/assets/` — оптимизированные WebP.
- `reference-assets/` — загруженные оригиналы для воспроизводимости, исключены из публикации.
- `scripts/` — получение оригиналов, извлечение проверенных рисунков, преобразование WebP. Для извлечения PDF нужен PyMuPDF. Исходные фоны берутся из соседней предоставленной папки `assets`.

В источниках отмечены два содержательных нюанса: датировка Кермека в новой публикации уточнена до 2,1–2,0 млн лет, но в сценах сохранён диапазон ТЗ; 3500+ бус относится к взрослому мужчине, а рядом находится модель двойного погребения подростков. Лицензии рисунков ИИМК не объявлены свободными: статус явно записан в источниках. Атрибуция фотографий сохранена; выполнены только уменьшение и конвертация. Все художественные фоны помечены как реконструкции.

## Vercel

Настройки Vite уже в `vercel.json`. Для `/#N` серверный rewrite не нужен. Публикуется только `dist`.

Постоянный деплой после входа:

```sh
vercel login
vercel --prod
```

## Ограничения проверки

Проверено автоматизированно в desktop Chromium. Реальная электронная доска, Firefox и Safari требуют отдельного прогона на целевом оборудовании; заявлять измеренные 30/60 fps для неизвестного устройства нельзя.
